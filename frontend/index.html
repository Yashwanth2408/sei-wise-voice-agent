How it works

Voice pipeline

01

Capture

Browser mic audio is sent through LiveKit to the backend pipeline.

02

Transcribe

Deepgram converts speech to text in real time so the agent can react conversationally.

03

Route

Groq-based routing keeps responses inside the Wise transfer-tracking FAQ scope.

04

Speak

Cartesia TTS returns a concise answer back to the caller with a natural spoken voice.

Tech stack

  • Frontend: Vanilla HTML, CSS, and JavaScript
  • Transport: LiveKit
  • STT: Deepgram Nova-3
  • LLM routing: Groq GPT OSS 20B
  • TTS: Cartesia Sonic

Key capabilities

  • Scoped support agent behavior
  • Real-time turn taking and transcript display
  • Fallback-safe call control and telemetry
  • Conversational voice handling

Scope

What the agent handles

In scope

Transfer status, delayed transfers, money received, transfer sent, proof of payment, estimated arrival, and other approved Wise "Where is my money?" questions.

Out of scope

Fees, exchange rates, account opening, fraud disputes, card topics, and any request that would require guessing beyond the supported FAQ.
